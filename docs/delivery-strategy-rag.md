# 投放建议使用 AdsAgent 与营销知识库

广告编辑框的「获取投放建议」调用 `/api/ai/strategy`，由 Koa 转发到 `/generate/strategy`。Python 不再绕过 Agent 直接生成策略，而是使用运行中的 AdsAgent 和已注册的 `knowledge_search` 工具。

## 调用链

1. 依据行业检索营销方法，并同时召回推广目标、人群与渠道、素材测试三个方向。
2. 使用现有查询改写、并行召回和重排流程。重排读取片段正文，避免长元数据挤掉正文。
3. 复用 EvidenceGate，保留通过检查的知识片段。检查的是能否支持下一步方法建议，不要求知识库证明完整商品投放方案或预测效果。
4. AdsAgent 结合商家描述和已检查片段生成结构化建议，包括建议目标、人群假设、出价测试方法、待补充数据和引用 ID。
5. 后端验证引用 ID 属于本次保留片段，返回对应标题、原文片段和来源链接。前端展示建议与可展开的知识依据。

## 边界

- 检索失败、证据检查失败或没有可用依据时返回明确错误，不冒充已使用知识库。
- 推广目标必须由模型明确返回，不能自动填入「需明确推广目标」。
- Koa 按广告 ID 读取当前出价、素材及同一统计窗口的账本指标、分日记录和预算。已有记录按已投放广告分析；复制或新建广告不继承原广告的投放历史。商家仅补目标、日预算、天数和最高点击出价，成交目标可补单笔利润。AdsAgent 返回具体金额，后端校验金额不超过商家上限、日预算和系统可保存的出价范围。无历史的新广告采用成本上限50%的起始试投规则，明确这是试投价。点击目标不索取无关转化数据。
- 人群与兴趣是待测试假设，不是已确认的客户画像。生成建议不会修改广告或发起投放。
- 对本机 Chroma 的特定 HNSW 查询错误，在不超过 10000 个片段时使用原有向量做精确余弦检索；不改变、删除或重建知识记录。更大知识库仍明确报错。
- MiniLM 使用 CPU 推理，保持相同模型，避免 macOS CoreML 并行查询卡顿。共享聊天默认超时未改；投放建议独立设置检索阶段 5 秒、证据检查 16 秒，生成沿用模型客户端的 18 秒上限。

## 验证

相关测试覆盖：检索内容进入 AdsAgent、无关内容过滤、引用 ID 校验、缺少目标字段拒绝、检索失败不生成、HTTP 返回来源、确定性多方向召回、重排读取正文、HNSW 错误时保留真实 ID/向量/来源。

2026-10-14 本地验证：49 项相关 Python 测试通过，前后端构建通过。真实浏览器按钮调用返回 200，证据检查为 sufficient，页面显示推广目标、出价测试方法和三条知识依据。验证记录见 `docs/validation/delivery-rag-live.json`，截图见 `docs/validation/delivery-rag-ui.png`。

## 出价建议的数据与界面

- `GET /api/ai/strategy-context` 返回所选广告的投放状态、同一周期指标、当前出价和预算默认值。读取与生成接口均要求运营身份。
- `POST /api/ai/strategy` 的投放指标由 Koa 根据广告 ID 重读；浏览器不能通过请求里的 `delivery` 伪造历史指标。预算、目标、天数、点击出价上限来自本次商家设置。
- 按本次需求，账本中有记录的广告作为已投放广告，账本数字作为当前演示业务的投放数据。原始账本仍保留原来源信息。
- 有记录的广告自动带入数据和限制；新广告不要求虚构曝光、点击或订单，只补试投计划。复制广告同样按新广告处理。
- 本项目账本按 CPC 使用，界面明确标注“元/点击”。模型结合数据和营销知识选金额，后端限制金额不超过最高点击出价和日预算。新广告无历史时采用上限50%的明确试投规则。
- 展示的数据摘要、预算乘法、调整百分比由后端计算；不把历史平均 CPC 等同最高竞价上限，不把后续计划预算冒充历史预算。
- 点击目标不显示无关的成交/加购补充清单。没有视频不作为无法建议出价的条件。
- 界面先展示已读取数据，再展示本次限制和建议结果；桌面两列表单，手机单列；仅弹窗正文滚动，关闭和保存按钮固定在上下边缘。
- “应用到出价”只修改当前编辑框，保存广告仍由原来的“确定”按钮完成。新建/复制/切换广告时清理旧建议并隔离迟到响应。

补充：模型未给出有效调整金额时，已投放广告保留当前出价，并受商家新上限约束；不会强行猜测调价幅度。新广告的起始金额由试投规则计算。金额来源通过 `bidBasis.amount_source` 返回。

最终验证：53 项 Python 测试、5 项 Node 测试及前后端构建通过。桌面真实调用中，已有广告返回并应用 ¥0.70；新广告在 ¥0.80 上限、¥30 日预算、3 天计划下返回并应用 ¥0.40。测试未提交广告保存。记录与桌面截图见 `docs/validation/ui/bid-advice/`。
