## 边界与验收

- B每题读图；C1先复用独立初始观察，缺项最多读原图一次，补充观察在同图后续新问题中复用。两组同模型、同阅读/回答约束，同图问题和组别随机交错。
- 初始观察不接触测试问题或gold；生成答案、路由、读图均不接触gold。脚本中预标注常量仅用于准备文件，不进入模型请求。
- 透明图统一白底合成并冻结哈希。答案来自运行前主代理看图标注，未用受测模型答案作gold；不是人工独立金标准。近似图按来源家族隔离、每家族1张，目视未发现跨家族复制，但未经独立人工复核。
- 自动字段命中和来源ID合规不等于正文正确或引用支撑；数量、材质、投放效果、风格和受众标签均不当作已核验事实。
- 四类题仅覆盖主体、背景/指定区域颜色、真人手出现、真实销量不可核验；不覆盖细字OCR、复杂版式和检索召回。
- 预设观察质量下限：C1比B下降不超过2个百分点；速度目标：P95下降至少20%。只有观测结果、区间及人工审核都支持，才可作正式结论。
- family聚类配对bootstrap仅供探索。固定参考图且只有21个来源，不能推广到全部广告和线上流量。
- P95包括路由、读图、生成和本地编排，不含线上检索、上传排队。费用按官方常规价格估算，忽略缓存优惠；不是账单。初始观察准备成本单独保留于initial-observations.json，对C1完整计入总成本。
