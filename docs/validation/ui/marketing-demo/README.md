# 投放效果模拟看板

入口：数据分析 → 投放效果 → 模拟看板。沿用现有蓝色主题、指标卡和图表样式。顶部同一排依次选择广告、日期、素材。

广告选项来自当前已加载广告列表，可继续加载更多；素材选项根据广告的视频素材数量或图文/链接配置生成，切换广告时重置素材筛选。表格展示广告名称、素材类型及广告版本，不将广告版本冒充素材版本。没有广告或列表读取失败时显示空态，不添加固定的演示广告。

广告身份和素材配置来自现有列表；曝光、点击、订单、花费、收入全部是按广告 ID 与素材序号稳定生成的客户端模拟数据，不读取真实投放结果，不写入数据库。固定演示日期为 2026-10-01 至 2026-10-07，Asia/Shanghai。各素材每日数据与汇总来自同一组样本，金额内部使用分，日期或素材筛选同时更新指标、漏斗、趋势和表格。ROAS 不是利润率。

已删除业务报表查询入口、查询表单、历史快照及估算工具；只保留模拟投放看板。
