# 广告与素材统一（2026-10-13）

现有本地库：18 条广告、17 份去重素材、18 条素材关联。正文和视频一致性核查：0 条差异。

## 数据规则

- 广告 ID 独立保存标题、发布者、落地链接、出价、累计点击和版本。
- 素材 ID 为正文和有序视频列表的 SHA-256。同样内容自动复用；多条广告引用同一素材。
- 素材为不可修改的内容快照。修改广告正文生成另一素材，其他广告的素材不随之改变。
- 删除广告级联删除关联，保留素材；素材库包含未使用素材。
- 广告列表、详情、公开列表通过同一 SQL 投影读取。旧广告正文/视频列继续作为兼容字段，并由同一事务同步写入；展示优先取素材库。
- 保存、复制、删除后刷新共享广告列表；Agent 任务成功和窗口重新获得焦点也会刷新。
- 素材库按独立分页读取，不受广告搜索、广告加载页数影响；支持显示使用数量和使用素材新建广告。
- 用户随后指定以原投放效果面板的数据为标准：已恢复原面板模拟数据，管理界面共用其计算规则和日期。后端原始计数保留，参见 ../performance-standard/README.md。虚构视频时长仍已移除。
- 生成工作台的输入附件、待审核生成结果仍按品牌权限保存在 Studio；本次素材库整理的是已保存广告中的正文及视频，没有把未审核结果自动投放。
