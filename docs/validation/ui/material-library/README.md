# 素材卡片与删改验收

卡片统一标题、预览高度、三行文案、指标区和底部操作栏。支持完整文案与多个视频展开。

编辑按钮携带素材 ID 跳转到素材生成工作台，读取名称、文案、视频地址；保存后返回素材库。已有内容采用快照隔离：改文案或视频生成新内容快照，旧快照从素材库隐藏，已发布广告保持原内容。只改名称则更新库内名称，不改广告名称。删除采用归档隐藏，仍保留关联广告引用，不删除视频文件。

服务端 GET /api/materials/:id、PUT /api/materials/:id、DELETE /api/materials/:id 均要求运营身份。写入沿用业务幂等键、事务和审计记录。迁移 021_material_library_archive.sql 新建归档表，已应用到本地数据库；不修改已执行迁移的 SQL。

验证：客户端和服务端构建通过；真实隔离 MySQL 测试 material-library.test.cjs、materials.test.cjs 通过（修改隔离、删除持久化、授权、校验、请求重放）；浏览器 fixture 检查卡片底部对齐、编辑跳转/预填/保存返回、第二次编辑、删除确认/取消，以及 320–1280px 无溢出。浏览器验收不修改用户现有广告，不调用付费生成。运行服务通过已配置身份读取素材库返回 200。

## 商家上传准备好的素材

素材库“上传素材”进入工作台的独立上传表单；编辑既有素材也使用相同上传控件，视频地址文本框已移除。支持 JPG/PNG/WebP 图片和 MP4/MOV/WebM 视频，多选、预览、移除及保存。上限为单文件 100MB、总计 20 个；不触发模型分析、付费生成或广告发布。

POST /api/materials/upload 要求运营身份，校验 MIME/扩展名与文件大小；POST /api/materials 沿用事务、幂等和审计保存素材。图片通过 022_material_images.sql 单独保存并纳入内容快照哈希，迁移已在本地应用。原广告引用保持不变。

真实 MySQL 测试验证 PNG 文件实际写入、图片入库与读回、新建素材、不支持格式拒绝、原广告隔离；浏览器 fixture 验证图片与视频上传控件、预览、移除、保存返回素材库和窄屏布局。upload-desktop.png 为上传表单验收截图。
