# 按原投放效果面板统一数据（2026-10-13）

按用户要求，恢复原投放效果面板，保留其数值、漏斗、趋势、素材对比及两档日期。该面板原本使用模拟数据，现在作为管理界面投放数据的统一标准。

- `client/src/utils/performance.ts` 是原面板计算规则的唯一实现；提取时保留广告/视频 ID 的种子、金额单位（分）、日权重及末日补余规则。
- 广告管理（包含导出和点击排序）、广告详情、广告概览、广告卡片、助手面板摘要均引用此实现。
- 广告列表和详情展示曝光、点击、订单、花费、净收入；不再将后端累计点击当作这份日期范围内的投放效果。
- `PerformanceContext` 共享统计日期。在投放效果面板选择 10 月 1–7 日或 10 月 5–7 日后，导航至其他模块仍使用该日期。
- 素材库按所有关联广告汇总，不受广告搜索和已加载页数影响。服务端返回关联广告 ID 和视频数量；客户端使用同一规则汇总。没有广告使用的素材为 0。
- 后端原始广告配置、真实累计点击计数仍保存；本次没有向数据库写入模拟业绩，也没有修改投放排序或点击写入逻辑。
