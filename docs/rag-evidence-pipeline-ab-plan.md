# 同源证据→字段选择→缺项补读→程序校验：分步对照方案

日期：2026-10-16。仅隔离实验，不修改线上模型、业务库或历史成绩。

## 问题与假设

上一轮明确案例关联可确认来源，但联合题12/21、严格摘录1/21；同时存在无关字段、漏填视觉字段、引用超长或改写。此次检验四步工程改动各自增加多少任务完成度、延迟、Token及费用，不能把结果称为广告创意质量提升。

## 分组

| 组 | 做法 | 相邻对照 |
|---|---|---|
| A | 三份真实混合来源＋明确关联＋完整视觉观察，沿用上一轮提示 | 基线 |
| B | 按原图hash和冻结来源清单自动组装同源上下文，只保留对应来源 | B−A：确定性证据装配 |
| C | B基础上仅取本题所需字段、对应观察和正文；显式列出所需字段 | C−B：证据裁剪与字段需求，作为一组改动 |
| D | C基础上，手/腕字段缺少明确证据时最多补读原图1次，形成带区域的布尔观察 | D−C：补读成本与效果 |
| E | 对D的同一份原始输出执行字段、引用、摘录校验；只从已验证同源证据补齐字段和截取原文 | E−D：程序处理，无额外模型请求 |

E是D同一模型收据的离线后处理，不是另一次独立生成。计时与费用继承D的全部模型请求，再加处理开销；分别记录原始回答和最终输出。禁止把程序填字段、截取原文称为模型理解提升。

## 数据与冻结

- 21张图/21来源家族，沿用上一轮素材与4类题：真人手/腕、来源记录署名、两者联合、12—60字符连续原文摘录。84道主测试，均为已使用题，不是新的盲测。
- 另提前冻结6道构造压力题：3道正确来源缺失，要求拒答；3道输入关联指向干扰来源但正确来源仍在候选池，检验来源清单能否纠正错误关联。压力题单列，不混入真实主测试质量分数。
- 原图、来源正文、来源清单、初始观察、提示、字段规则、评分器、问题与参考标签在调用前保存hash。
- 来源绑定由原始图片hash→采集清单source_url→上下文URL建立，不使用gold中的context_id/publisher推导待测输出。当前候选固定且通常包含正确来源，不测ANN或图像检索召回。
- 初始观察继承同一模型旧收据；计入各组准备成本。若切模型，重新为该模型建立初始观察，不共享不同模型的观察。
- D只把已有观察中明确出现人手/手腕的陈述视为覆盖；没有提到不能推断不存在。未覆盖时读图，false必须来自全图检查后的明确不存在陈述。
- 各题间不累计补读结果，避免后面题目因组别顺序获益；候选、题序、题内A—D调用顺序随机冻结，串行执行。

## 评分

1. 必需字段：严格布尔值、采集记录署名NFKC/空白/大小写归一化匹配；不使用颜色或主体中文别名。
2. 引用：图像ID和同源文本ID正确；摘录必须为原文连续片段且长度12—60字符。
3. 严格合规：仅允许本题字段，其余为null；拒答状态与字段相符；未知引用、遗漏字段、超长或非原文引用均失败。
4. 分开报告任务完成率、严格合规通过率、视觉字段正确率、无依据输出、正确拒答；正确拒答不当作视觉理解错误。
5. P50/P95分装配、模型回答、补读、程序处理计时；D/E同时报告需要补读/无需补读两个子组。报告每类题，不能用任务混合比例掩盖问题。
6. 源家族聚类配对区间；只有21来源，且视觉标签是代理预标注、未人工独立复核，不能宣布统计非劣或泛化结论。

## 验收与预算

- 预设目标：E联合字段任务完成率≥95%，严格输出合规≥95%，错误来源引用为0；主测试任务完成率相对A不下降。
- 目标是质量—成本取舍；P95和费用均不预设必然下降。D/E相对C的额外读图必须单列，计入总成本。
- 默认doubao-seed-2-0-lite-260428；温度0，关闭思考。最多650次模型请求，估算预算5元，逐次保留收据，不自动重试不确定请求。
- 若明确429/SetLimitExceeded：先查看用户指定方舟控制台剩余免费额度，选支持所需模态/结构化输出的模型；无合适免费模型再mini。同一道题A—E使用同一模型；中断块保留但不混入配对对照，换模型后整题重新执行。按模型分开报告，不跨模型合并归因。
- 本实验不证明创意文案更有吸引力、商家真实效果更好、GraphRAG已实现或全链路检索提速。程序校验也不等于独立事实核验。
