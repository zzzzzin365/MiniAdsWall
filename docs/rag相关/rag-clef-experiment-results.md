# Clef 片段判断实验：部分结果

2026-10-11，比较当前 LLM 片段判断与 Cloudflare Clef。后续充分性检查、缺失信息解释与回答生成均使用 `nvidia/nemotron-3.5-lightning:free`，提示相同；原配置模型返回 404，仅通过实验 `--model` 覆盖，没有修改生产模型配置。

两道校准集冒烟题跑通后，固定两组阈值 0.7，开始 56 道冻结测试题。未调整或校准阈值。尝试到第 12 题时，OpenRouter 免费模型每日额度耗尽，连续 429 触发 runner 自动停止；接口明确返回 `free-models-per-day`，账号余额为 0。本次没有购买额度。不是完成了 56 题。

仅 7 对具有完整答案与评审，其中可回答 3 题、不可回答 4 题。其余 5 对因超时、提供方限流或缺失评审，不进入质量比例；原始记录全部保留。

## 经助手对照原始答案和参考数据复查

| 指标 | LLM 判断片段 | Clef 判断片段 |
| --- | ---: | ---: |
| 给出错误事实或错误计算 | 1/7 | 1/7 |
| 可回答题却拒答 | 0/3 | 2/3 |
| 核心答案正确 | 5/7 | 4/7 |
| 片段判断耗时中位数 | 2.20 秒 | 1.12 秒 |
| 完整回答流程耗时中位数 | 6.16 秒 | 3.61 秒 |

这是助手复查，不是独立人工评审。自动模型评审存在错误：对未来利润问题误读可回答标签，甚至把排序分当作收益依据；另一次把“已有曝光却声称缺失”记成事实错误，与同类问题的误拒答口径不一致。复查统一了这些分类；保留原报告，并另外保存修正理由。

### 直接观察

- 两组都把单日点击除以七日曝光，输出 0.53%。Clef 保留了正确的 CTR 规则，后续 LLM 仍违反同窗口要求。
- 两道 CTR 题分别已有曝光 18300 与 16400，Clef 组后续 LLM 却称缺曝光并拒答。片段判断通过不保证充分性检查正确。
- 单价冲突题，Clef 只保留了结算公式，过滤了两条冲突单价。后续只得出“缺单价”，没解释冲突。若继续迭代，应检查过滤是否损失了必须保留的反例或冲突证据。
- 增量利润题，Clef 组保留了历史数据不能证明未来收益的限制；后续拒答并要求未来变化数据与模型，较 LLM 组的缺失信息说明更贴近参考要求。

**本次没有观察到 Clef 减少最终错误回答，且多了两次误拒答。**阶段耗时较短，但完整流程变快部分来自拒答跳过生成，不能算作无代价提速。不能依据 7 对不完整、非随机留下的样本证明 Clef 更好或更差，也不能推断 Jev 性能。

Clef 的 12 次测试调用输入费估算总额约 $0.00237，按调用返回的 token 使用量及官方单价计算，不是实际账单金额。生成和评审使用免费模型；缺失费用不记零。
