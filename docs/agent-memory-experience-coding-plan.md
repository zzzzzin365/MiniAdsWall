## 最小验证清单

- 单元：预算裁剪、摘要水位、偏好冲突、版本 CAS、案例条件与有效性。
- MySQL 集成：终态与任务原子性、唯一键、重复领取/租约过期、旧 fence 和取消。
- 链路：浏览器→Koa→托管→上下文快照→模型输入→成功终态→记忆任务→新会话读取。
- 故障：Redis/Chroma 中断、对象缺失、上下文恢复后撤回、摘要修复失败、同步身份伪造。
- 效果：冻结集 A/B/C 与消融；成本纳入后台提取/摘要，不只看单次模型输入。

验收命令和报告路径由实施阶段按实际测试文件补齐。本文不声称测试已通过。
